## Overview

The trainer attaches to Warrior Cats: Clans of the Forest as a lightweight overlay and exposes 41 runtime options grouped into five modules. Press **INSERT** in-game to open the menu. Every option toggles live — no save editing, no console commands, no restarts required. Changes take effect the moment you flip a switch.

Three clan presets ship by default. Each preset bundles the most-used combinations for a specific playstyle and activates everything in one click. You can edit any preset or build new ones from inside the overlay menu; all configurations persist between sessions in the `profiles/` folder.

## Installation

1. Download and extract the archive from the link above
2. Run the installer and choose an install path
3. Launch the trainer as **administrator**
4. Start Warrior Cats: Clans of the Forest
5. Press **INSERT** in-game to open the overlay
6. Toggle modules or activate a preset — changes apply immediately

Settings auto-save on exit. To reset to defaults, delete the contents of `profiles/`.
